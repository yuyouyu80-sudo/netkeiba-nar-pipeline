2. F0 評価の土台

2-1. 競走中止の馬を候補に入れた

これまでの評価は完走した馬だけから組を作っていたため、「どの馬が中止するか」を前もって知っていたのと同じで、的中率が少し甘く出ていました。発走した馬(確定単勝オッズがある馬)は全員を候補にし、中止・失格の馬を含む組は外れとして数えます。出走取消・除外は候補に入れず、記録した後に取消になった場合は精算で返還にします(F4)。

  • 中止の行: 2011〜2020年で $nf_rows 行。学習・評価に使ったのは $nf_used 行(評価の3年で $nf_test 行、$nf_races レース)。
  • 中止馬の発走前の特徴量(能力値・血統+実績・斤量・距離の変更)は、完走馬と同じ作り方で作りました。係数は完走馬だけで推定し、完走馬の値は1つも変わらないようにしています(テストで確認)。
  • 中止馬のいるレースの10点の的中率: 人気どおり $nf_hit_m、M5 $nf_hit_5。

前(完走馬だけ)と後(発走した全馬)— 2018〜2020年、約1万レース

上積み=「実際の払戻 −(同じ人気の組の平均の払戻)」を賭け金で割ったもの。人気どおりに買ったときに0になるよう作ってあります(陰性対照)。

2-2. 買い方6通りの比較(人気をそろえた上積み)

組の確率の高い順に「決まった点数」買う方式と、「確率の合計が決まった値に達するまで」買う方式(上限30点)。陰性対照は人気(オッズ)の側で同じ規則を当てたものです。

$trules
  • 人気どおりの上積みは、どの規則でも区間が0を含みます。物差しは狂っていません。
  • 累積の方式は、M5 では固定の点数より上積みが悪い傾向です(自信のあるレースほど人気の組に寄るため)。主ルールの候補は固定の点数を中心にします。

2-3. 層ごと(10点買い)

$tlayer

少頭数では M5 の上積みがプラス寄り、15頭以上ではマイナス寄りですが、どれも区間が0を含みます(層は事前に決めた5つだけ)。

2-4. オッズに無い情報の量

組の確率を「a×log(モデル)+ b×log(人気)」で表す式を、2018〜2020年の全組で当てはめました。a が0より大きければ、モデルは人気に無い情報を持っています。

  • a = $inc_a(SE $inc_se、日付×競馬場でまとめた頑健な SE)、z = $inc_z。b = $inc_b。
  • 人気だけの式に比べた改善は1レースあたり +$inc_dll。人気(b)がほぼ全体を決めていて、モデルの寄与は小さい。

2-5. 物差しの点検

  • 当たり組の実際の人気との対応: 払戻の表の「人気」と、確定単勝オッズから作った組の確率の順位は、順位相関 $pop_sp。2倍以内に収まる割合 $pop_x2($pop_n 組)。
  • 発走前の3連複オッズとの対応($px_n レース、2026-10-03〜): 組の確率の順位相関の中央値 $px_sp、上位10組の重なり $px_ov。ただし傾きは $px_sl で、実際の3連複の市場は単勝から作る確率より人気薄を高く見ています(単勝からの近似は人気の差を広げすぎ)。控除率の中央値 $px_to。
  • このずれは「人気をそろえた上積み」の基準(実際の払戻の平均)には入っているので、評価の結論は変わりません。発走前の3連複オッズの記録は続けます。

4. F2 能力値の改良(生年月日を使わない分)

これまでの能力値(タイムから作る走ごとの能力値と、1次元のカルマンフィルタ)に、次の4つを足しました。どれも「その日より前」の情報だけで作り、テストで確かめています。

  • 芝・ダ別の状態: 芝とダートの能力を別々に持ち、相関でつなぐ。初芝・初ダの馬は、もう一方の成績から相関の分だけ推し量ります。
  • 父の産駒の能力(月ごと): 前月末までの産駒の能力値を、年齢・時期・芝ダの平均を引いてから父ごとに平均(本人は除き、走の少ない父は0へ縮める)。初出走の予想の起点にも入れます。
  • 母のきょうだい: 同じ母の他の馬の能力から、父の分を引いたもの(本人は除き、強く縮める)。
  • 主戦距離との差: 今回の距離と、それまでの距離の平均との差(対数)とその大きさ。
