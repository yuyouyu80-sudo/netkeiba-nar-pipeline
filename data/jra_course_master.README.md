# data/jra_course_master.csv

予想ファクター充足度マップ Tier4項目8(コースマスタ整備)。JRA10場のコース仕様
(直線距離・高低差・周長・幅員・回り方向・設定距離)を1行1場でまとめた恒久・静的な
参照表。開催のたびに変化するデータではないため、他のTierと異なり日次の再取得スクリプトは
持たない(re-fetchが必要になるのはJRAが物理的にコースを改修した場合のみ)。

## 出典・作成方法

各行の`source_url`列(`https://www.jra.go.jp/facilities/race/{venue}/course/index.html`)を
2026-09-02に直接取得し、掲載されている表を人手で確認・転記した(このページ群は競馬場ごとに
HTML構造が微妙に異なり—`<caption>`でラベル付けされる場合と`<h3>`見出しでラベル付けされる
場合が混在し、さらに阪神・京都・新潟・中山は芝コースが内回り/外回りの複数構成を持つ—
単一の自動パーサーで全10場を均一に処理するのは非現実的と判断し、事後検証可能な形で
手動確認する方針にした)。

## turf_*列の代表値について

内回り/外回りの複数構成を持つ場(新潟・中山・京都・阪神)は、**外回りの値を代表値として
turf_straight_m/turf_elevation_m/turf_circumference_m/turf_width_mに採用**し、内回り側の
数値は`notes`列に記載した(完全な内回り/外回り別データが必要な場合は、`notes`列の記載を
手がかりに`source_url`のページを直接参照すること)。新潟の直線1000m専用コースも同様に
`notes`列に注記のみ。

turf_circumference_m/turf_width_mは、複数のレール位置バリエーション(A/B/C/Dコース)がある場
では**Aコース(最内)の値**を採用している(内外に応じて周長が変わるため、他のバリエーションは
`source_url`のページを直接参照)。

## 意図的にこの表に含めていない項目

充足度マップTier4項目8では「最初のコーナーまでの距離」「コーナーの回数」も候補に挙がって
いたが、実際にJRA公式のコース仕様ページを確認したところ、**これらは距離(1200m/1600m等)ごと
の発走ゲート位置に依存する値であり、コース仕様ページには掲載されていない**(掲載されて
いるのはコース全体の直線距離・周長等の恒常的な仕様のみ)。距離別に必要な場合は、コース図
(平面図画像、`source_url`ページ内の`<img>`)からの目視判読か、別途のより詳細な資料が必要
になるため、今回のスコープには含めていない。

## 「小回り/平坦」等の分類について

急坂の有無・小回り/平坦適性といった**カテゴリ分類はこの表では行わない**(データ収集用
セッションの役割ではなく、`turf_elevation_m`等の生の数値から閾値を決めて分類するのは
データ予想用セッション側のシグナル設計作業、という役割分担に合わせた)。
