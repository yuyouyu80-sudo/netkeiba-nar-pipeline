## 0. 位置づけ

- 目的: 取得済みの全JRAレース結果(2011〜2026)で、ディープラーニングが**確定オッズ(市場)に対して増分を持つか**を判定する。「DLで勝つ」ことは前提にしない。
  「差なし」も正当な結論として報告する。
- 旧事前登録(`debut_pedigree_PREREGISTRATION_2026_10_03.md`)の「本格DLはH1相当を満たすまで着手しない」は、**ユーザー依頼により本検証で上書き**する
  (ゲート前にDLを実施する。ただし採否基準は不変)。旧文書は書き換えない。
- ユーザー決定: torch CPU版を専用venv(.venv_dl)へ導入、**馬場状態は入力に入れる**、**今走の馬体重・増減は主解析から除外**、新馬・未勝利を含める。

## 1. データ・母集団(固定)

- ソース: `data/race_results/{2011〜2026}`(JRA)。2026-10-03 21:38 に2011〜2016年のバックフィルが完了(各年約3,454レース)。
  凍結: 特徴ストア構築時に**ファイル内容のsha256とレース日の上限(2026年はその時点の最新確定日)**をmanifestに記録し、以降に追加された行は使わない。
  mtimeは使わない。直近300秒以内に更新されたファイルは読まない(収集中ファイルの破損防止)。
- 母集団: 平地(芝・ダート)、障害除外、`is_starter`(オッズ・人気が数値)で出走5頭以上、取消・除外は頭数から除く、中止(中)は出走扱い。
  新馬・未勝利を含める(層別で報告、既存の評価母集団[新馬・未勝利・障害除外]での結果も副表として併記)。
  重複(race_idのずれによる二重登録)は`jra_history._dedupe_race_id_drift`で除去し、(馬, 日付)の重複ゼロをassertする。
- クラス: `race_potential.class_ordinal`(2026-10-04に旧表記「500万下/1000万下/1600万下/(重賞)」を追加済み)で正規化し、全年でNaNがゼロであることを検査する。
  新馬と未勝利は別カテゴリ(ordinal 0内で`kind`を保持)。
- 血統: 2017年以降の出走馬はほぼ全頭被覆(99.9%)。2011〜2016年の出走馬は被覆が31〜76%(2026-10-04時点)で、**主解析の学習開始は2017年**とする。
  2013年開始の学習(血統欠損フラグ付き)は感度分析(予算が許す場合のみ)。
- 履歴: 2011〜2012年は特徴量のウォームアップ専用(直近365日・直近2年の窓を確保するため)。学習・検証・評価には使わない。
- 馬柱(2026年7〜9月のみ)・騎手/調教師プロファイル(スナップショット)・発走前オッズ履歴(2026年9月以降のみ)は主解析に使わない。

## 3. モデル(固定)

| 記号 | 内容 |
|---|---|
| M0 | 市場のみ。`u=β·log p_mkt`、βを推定 |
| M0+ | 市場の文脈別較正のみ(βを頭数帯×芝ダ×距離帯で層別、log p_mktの2次項、人気順位、馬番/枠、クラス) |
| M1 | 条件付きロジット+特徴(L2)。λ = λ0·(学習レース数/3000)、λ0 ∈ {1, 10, 100, 1000} |
| M2 | HistGradientBoosting: max_depth ∈ {3,5} × learning_rate ∈ {0.05, 0.1}、min_samples_leaf=100、l2=1.0。予測をレース内正規化 |
| M3 | sklearn MLPClassifier: hidden=(32,)、alpha ∈ {1e-4,1e-3,1e-2,1e-1}、max_iter=300、early_stopping=False |
| c0/d0 | M2/M3の対照(入力は市場と頭数のみ) |
| DL(B) | `u=β·log p_mkt+f_θ(x)`(主仮説)。fの最終層はゼロ初期化、βにweight decayなし、M0+と同じ最適化・学習窓、市場は入力に入れない |
| DL(B0) | DL(B)と同じ構造・学習設定で、入力はレース条件+馬番/枠のみ(馬固有の履歴・ID・血統・騎手を入れない) |
| DL(A) | 市場なし。入力に今走のオッズ・人気を入れず、過去人気なしの1設定のみ。**報告のみ**(ゲート対象外) |

DLの構成(固定): パラメータ総数の上限=学習レース数の約1/10(1〜3万)。初版は自己注意なしの1層版(数値ブロックLinear+過去走の小型GRU+祖先ID/系統カテゴリ埋め込み)、
レース条件はFiLM/連結、出力ヘッドは「芝ダ×距離帯」で分ける。新馬(過去走が全て空)は過去走マスク+新馬フラグ。損失=勝ちsoftmax+0.5×PL(2着・3着、項別マスク)。
AdamW、コサイン減衰、バッチ128レース。ハイパラは2通り: (d=32, dropout=0.1, wd=1e-4) と (d=32, dropout=0.3, wd=1e-3)。**開発フォールド(テスト2021の検証年=2020)で1回だけ設定とエポック数を選び、全フォールドで凍結**する。
シードは全フォールド同一の3本(1,2,3)、予測はロジット平均(単一シードの結果も併記)。自己注意2層への拡張は、1層版がH1の前提(ΔLL>0の点推定)を満たした場合のみ、追補として日付付きで固定してから実施する。
同着: 勝ち尤度の母集団は単独1着レースのみ(既存と同一)。PL項は2着・3着を項別にマスクする。

## 4. 評価設計(固定)

- ローリング前向き。テスト年=2021〜2026(2026は部分年)。学習=2017〜(t−2)、検証=(t−1)(ハイパラ・エポック選択専用)、t年は一度も学習・選択に使わない。
  **全モデルを同一の学習窓(〜t−2)で比較**する。〜(t−1)で再学習する版は感度分析。年1回の再学習。
- 標準化・prior・語彙・祖先統計の平滑パラメータは各フォールドの学習窓のみから算出する(テスト期を含めない)。
- 主指標: 勝ちΔLL(モデル−比較基準、ローリング前向き合算)。ブートストラップ: 開催日×競馬場ブロック、n=10,000、seed=20261004。感度分析として日単位ブロック。
  CIはフォールド間のモデル分散・シード分散を含まないため、シード別ΔLLの散布を併記する。
- 副指標: 上位3着PL尤度、レース内Spearman、較正(10分位・傾き・切片・ECE、p_model/p_mkt上位群の実測÷予測勝率)、的中率(単勝上位1頭・複勝上位1頭・3連複box4〜6)。
- 回収率(参考扱い・ゲートに使わない): 主指標は2系統のみ — (i)単勝 EV(=p_model×odds_final)≥1.1 の馬を全頭買う、(ii)複勝: モデルの3着以内確率が最大の1頭を各レース買う(払戻は`data/payouts`で事後精算。複勝オッズは過去分が存在せず事前EVは作れない)。
  他券種・他のEV閾値(1.0/1.2/1.5)は探索扱い。EV閾値は検証年で選びテスト年で固定する。払戻上限は主表を100円あたり10,000円(100倍)でキャップ、上限なしを併記。同着は`payouts`で精算する。
  全ての回収率表に「確定オッズ(odds_final)と確定払戻で計算。実運用は購入時点のオッズでの再評価が必要」と明記する。
- 層別(報告のみ、探索): 新馬/未勝利/1勝以上/OP・重賞(件数不足で報告のみ)/芝・ダ/頭数帯(≤10,11〜14,≥15)/人気帯/2歳新馬・3歳新馬/牝馬限定。
- 年別解釈の注記: 2020年の無観客開催、2019→2020のクラス改称。

## 5. 仮説と採否ゲート(固定)

| 仮説 | 内容 | 通過条件 |
|---|---|---|
| **H1(主)** | DL(B)が市場の文脈別較正(M0+)を上回る | 勝ちΔLL(DL(B)−M0+)の95%CI下限>0 **かつ** 年別ΔLLが正の年が6年(2021〜2026)中4年以上(符号条件は補助。帰無でも約34%通過するため、判定力はCI条件が担う) |
| H1' | 馬固有情報に増分がある | ΔLL(DL(B)−DL(B0))の95%CI下限>0 |
| H2 | DLが条件付きロジットより優れる | ΔLL(DL(B)−M1)の95%CI下限>0。H1のみ通ってH2が通らなければ「DLは不要、条件付きロジットで足りる」と結論 |
| 付帯 | 偶然・実装ミスの除外 | (a)レース内シャッフルのプラセボ(最終2フォールド×シード1本×10回)の帰無分布(平均+1.645SD)を、同じ2フォールドの実測合計が上回る (b)較正の傾きが0.9〜1.1 (c)増分が1つ以上の特徴群に帰属(アブレーション) |

- 多重性: 主=H1の単独検定。H1' → H2 は H1 通過後にこの順で検定する固定順序。副次・層別・アブレーションは「探索」と明示し、探索の族(層別12セル+アブレーション6群)にHolm補正を掛けて報告する。
- (A)・回収率・的中率はゲートに使わない。H1を採択しても、回収率は購入時点のオッズでの再評価まで実運用を推奨しない。
- H1棄却の場合: 「市場に増分なし。本番モデルは変更しない」と明記する。
- 旧M0に対するΔLLは参考値として併記する(ゲートはM0+基準)。

## 6. アブレーション(固定、探索扱い)

−G3(血統)/−G4(騎手・調教師)/−G1(過去走)/±馬場状態(G5内)/+G9(今走の馬体重)/±過去人気(G1内)。各シード1本で最終2フォールドのみ、全体でも可。

## 7. 検出力(MDE)の手順(数値は追補で埋める)

- 式: MDE ≈ (1.96+0.84)·sd_block/√B(Bはテスト期のブロック数≈1,600、sd_blockはブロック別ΔLL合計のSD)。n_effはレース数ではなくブロック数。
- sdの推定: テスト年を使わず、≤2020年の検証データでM1−M0+のブロック別ΔLLから推定(P2完了後に追補として記録)。
- 効果量(真の効果が0 / 0.001 / 0.003 / 0.005 nats/R)ごとのH1通過確率をシミュレーションで示す。0.005は先行最良値(案C型の確定オッズ上積み)。
- ΔLLから回収率への換算(推測): 乖離のrmsは約√(2·ΔLL)。ΔLL=0.003/Rで約8%、単勝控除20%を超えるには選択馬群でp/p_mkt≥1.25が必要。
  検出不能(MDEが0.005/Rを超える)と出た場合は、DL本実行を縮小版(1設定・2シード)に切り替える。

## 8. リーク検査(全通過が必須、1件でも差分があれば停止)

1. 摂動テスト: 日付D以降の全行の結果列をランダム化して特徴を再計算しても、D当日を含むD以前の全特徴が変わらない(年×月で層化、年始・フォールド境界・2018-02-03東京のrace_idずれ日・長期休催明けを必ず含む)。
2. 馬ごとのPythonループによる遅い参照実装と、500件の層化抽出で全特徴を照合。
3. 参照日<レース日のassert。結果後の列のホワイトリスト検査。
4. 各特徴をM0+に単独追加した検証年ΔLLのスキャンと、既知のリーク特徴(カナリア)を意図的に混ぜて検出できることの陽性対照。
5. 語彙・標準化・祖先統計の平滑パラメータが各フォールドの学習窓のみから作られていること。
6. 整合テスト: DL(B)にf=0を入れたときの勝ち対数尤度がM0と一致。

## 9. 撤退条件

- P1リーク検査に差分が出たら原因特定まで停止。 - M1が全フォールドでM0に有意に劣化する場合は特徴実装ミスを疑いP1へ戻る。
- 1エポックが90秒を超える、またはメモリ不足が解消できない場合は、sklearn系(M1/M2/M3)の縮小版に切り替え、レポートに「DL非実施」と明記する。
- 影の運用(P6)はH1・H1'・H2をすべて通過した場合のみ。前向き約100レースで較正が崩れる、またはΔLLが負なら停止。
