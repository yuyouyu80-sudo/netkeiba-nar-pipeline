# 3連複「荒れ」(払戻1万円以上)の数値化(2026-10-05)

既存データの読み取りだけで作成(netkeibaへのアクセスなし、既存ファイルの変更なし)。障害戦は除外。

## 実行順
1. `python s1_build_races.py` … レース単位表 `out/races_all.csv.gz`(約15分)
2. `python s2_stats_model.py` … 15年版の集計とモデル(`out/s1_*`)
3. `python s3_2026_signals_and_misses.py` … 2026年7/11〜9/27版、上乗せ検定、外れ分析(`out/s2_*`, `out/s3_*`)

## データの注記
- 2015年・2016年1〜8月も race_results / payouts がそろっていた(各年約3,325レース)ため、欠けは無し。
- 障害戦: 名前に「障害」がある競走に加え、「○○ジャンプS」「○○JS」(芝ダ欠損ではなく「芝」で入っている)も除外。
- クラス: 500万下→1勝、1000万下→2勝、1600万下→3勝に正規化。L→OP、GI〜GIII→重賞。
- ハンデ戦・牝馬限定は元データに表記が無いため推定。ハンデ=斤量0.5kg刻みがある、または同年齢・性別補正後の斤量幅6kg以上
  (見習い減量と区別できないため保守的な判定で、実際より少なく拾う)。牝馬限定=出走全頭が牝。
- 予測に使ったのは発走前に分かる情報だけ(レース条件+確定単勝オッズ)。着順・通過順・上がり・当日馬体重は手順3の事後診断にだけ使用。

荒れ度スコア(ロジスティック回帰、2011〜2022学習→2023〜2025評価)

| 区分 | 条件のみ AUC | 条件+オッズ AUC | オッズのみ AUC | ECE(条件+オッズ) | 下位10%/上位10%の実際の万馬券率 |
|---|---|---|---|---|---|
| 一般 | 0.691 | 0.730 [0.718–0.744] | 0.730 | 0.015 | 5.9% / 67.6% |
| 新馬 | 0.719 | 0.748 [0.714–0.782] | 0.754 | 0.021 | 3.3% / 58.2% |
| 未勝利 | 0.638 | 0.692 [0.672–0.711] | 0.698 | 0.027 | 6.3% / 53.6% |

オッズがあれば、レース条件を足しても上乗せはほぼ無い(オッズが頭数や条件の情報をすでに含んでいる)。

効いた要因(単変量のAIC改善/1000レースの順、詳細は `out/s1_factor_importance.csv`)
1. Harville安い組の確率(単勝オッズから推定した「払戻1万円未満の組が来る確率」)… Q1 58.9% ↔ Q5 11.9%(一般)
2. 頭数 … 8頭以下 5% ↔ 17-18頭 57%(一般)
3. 上位3頭の支持率合計
4. 1番人気オッズ … 1.5倍以下 16% ↔ 4.1-6.0倍 58%(一般)
5. オッズのエントロピー
6. コース(競馬場×芝ダ×距離帯) … 一般で小倉・新潟・福島の芝1200m以下が53〜56%、京都芝1700-2000mは21%
7. 距離帯(一般は1200m以下が46%)
8. オッズのジニ係数
9. 競馬場(新馬で特に差が大きい)
10. 月(新馬)・年齢条件・2-3人気のオッズ比

その他: クラスは一般のなかで重賞45%・3勝42%、1勝35%と小さな差。ハンデ戦(推定)は50%(非ハンデは37%)。
牝馬限定・馬場状態・開催日目の差は小さい(不良馬場の新馬で48%など少数のセルを除く)。

## 3. 予想外れ分析(2026-07-11〜09-27)

予想の定義: (a) 予想順位(pred_rank)上位5頭の3連複BOX(3区分すべて)、(b) 3連複印フォーメーション(fmark、一般400レースのみ)。
いずれもファクターDB・fmark_backfill_404.json のバッチ計算値で、モデルの重み決定期間と重なる(インサンプル)点に注意。

| 区分 | 予想 | 的中×荒れた | 的中×荒れない | 外れ×荒れた | 外れ×荒れない |
|---|---|---|---|---|---|
| 一般 | 上位5頭BOX | 8 | 57 | 136 | 199 |
| 一般 | 3連複印 | 26 | 119 | 118 | 137 |
| 新馬 | 上位5頭BOX | 0 | 28 | 26 | 43 |
| 未勝利 | 上位5頭BOX | 4 | 87 | 80 | 122 |

外れ×荒れた(上位5頭BOX基準、一般136・新馬26・未勝利80)の理由。判定は結果データから機械的に行い、複数該当あり。
主理由はE→C→D→F→G→A→Bの優先順で1つ選ぶ。

| 理由 | 判定基準 | 一般 該当/主 | 新馬 該当/主 | 未勝利 該当/主 |
|---|---|---|---|---|
| A 人気馬凡走 | 1番人気が4着以下、または上位3人気のうち2頭以上が4着以下 | 124 / 23 | 23 / 0 | 73 / 27 |
| B 穴馬激走 | 7番人気以下かつ予想6位以下の馬が3着内 | 107 / 1 | 20 / 0 | 71 / 2 |
| C 展開ずれ | 3着内馬の実際の4角位置とAI展開予想の差が平均で頭数の30%以上 | 38 / 30 | 11 / 11 | 21 / 20 |
| D 馬場・枠の偏り | 3着内が全頭1-3枠か全頭6-8枠、または重・不良馬場 | 26 / 18 | 8 / 6 | 16 / 12 |
| E 当日アクシデント | 予想上位5頭か上位3人気が取消・除外・中止・失格、または馬体重±20kg以上 | 16 / 16 | 0 / 0 | 4 / 4 |
| F データ不足 | 3着内に過去走データなし、または初芝ダ×初距離の馬 | 71 / 37 | 26 / 9 | 14 / 8 |
| G モデルの弱点 | 人気上位5頭は3着内馬を2頭以上含むのに、予想上位5頭は1頭以下 | 36 / 11 | 8 / 0 | 13 / 7 |

## 4. 逆指数「荒れない」(3連複1,000円以下、2026-10-05追加)

`ARERE_TARGET=katai` を付けて s2・s3 を実行すると、目的変数を「3連複払戻1,000円以下」に替えて同じ計算をし、`out_katai/` に出力する
(レース表 `out/races_all.csv.gz` は共通。列名は arere のままで、この実行では「堅い=1」を意味する)。

```
ARERE_TARGET=katai python s2_stats_model.py
ARERE_TARGET=katai python s3_2026_signals_and_misses.py
```

| 区分 | 15年の1,000円以下率 | 2026年7〜9月 | AUC 条件のみ / 条件+オッズ(2023〜2025) | 2026年のAUC |
|---|---|---|---|---|
| 一般 | 8.1%(2,302/28,309) | 7.3%(29/400) | 0.839 / 0.911 | 0.901 |
| 新馬 | 12.0%(526/4,377) | 13.4%(13/97) | 0.829 / 0.871 | 0.899 |
| 未勝利 | 12.8%(2,199/17,218) | 17.4%(51/293) | 0.717 / 0.837 | 0.885 |

- 効いた要因は荒れ度と同じ顔ぶれ(上位3頭の支持率合計、Harville推定、頭数、1番人気オッズ、エントロピー、10倍未満の頭数、コース)。
- 指数の下位10%では1,000円以下は0件、上位10%では約半数。
- 馬柱サイン10個の上乗せは無し(新馬は悪化)。
- 全体の1,000円以下率は2014〜15年7.3% → 2024年12.8%と上昇傾向。

## 5. 荒れ度指数 × 荒れない指数(2026-10-05追加)

`python s4_combined.py`(s2 を既定と ARERE_TARGET=katai の両方で実行済みであることが前提)。出力は `out_combined/`。

- 2指数の順位相関は −0.88〜−0.93(ほぼ裏表)。
- 合成指数 logit(荒れ度) − logit(荒れない) は、荒れの予測で荒れ度指数単独よりわずかに悪く(一般 0.730→0.723)、堅い予測でも荒れない指数単独と同等(0.911→0.912)。
- 2023年で重みを決め2024〜2025年で評価しても、もう一方を足したAUCの変化は −0.006〜+0.001。2026年7〜9月も同じ。
- 4区画: 一般の「荒れ度 高×荒れない 低」(35.6%)は万馬券率55.2%・1,000円以下0.1%、「荒れ度 低×荒れない 高」(50.5%)は20.9%・18.5%。食い違う2区画は計14%で中間(1,000円〜1万円)寄り。

## 6. レースごとの指数と予想3連複払戻額(2026-10-05追加)

予想払戻は log(3連複払戻) の分位点回帰(勾配ブースティング、2011〜2022学習)。
